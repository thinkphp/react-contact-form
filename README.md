# Formular de contact

Aplicație React construită cu Vite și CSS standard.

## Comenzi

- `npm install` — instalează dependențele.
- `npm run dev` — pornește serverul local de dezvoltare.
- `npm run build` — generează versiunea pentru producție în `dist/`.
- `npm run preview` — servește local versiunea construită.
- `npm run deploy` — publică `dist/` pe GitHub Pages.
